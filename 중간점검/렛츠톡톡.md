## 💡 프로젝트 주제
# 🗣️ Let's TalkTalk

**AI 기반 대화 주제 추천 서비스**

사용자의 현재 상황(소개팅, MT, 술자리, 데이트 등)을 AI가 분석하여
적절한 검색 조건으로 변환하고, Python 추천 엔진이 데이터베이스(SQLite)에 저장된 대화 주제 중 가장 적합한 주제를 추천해주는 서비스입니다.

## 🛠️ 기술 스택

### Backend
- Python 3.12
- FastAPI
- SQLAlchemy
- SQLite
- Pydantic
- Ollama (LLM)

### Frontend
- React
- Vite
- Tailwind CSS
